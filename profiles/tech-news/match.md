# AI models and tooling profile

Use this profile for news about AI model releases and capability changes, subscription plans and pricing, quotas and access restrictions, coding agents and developer tooling, API relay and proxy services, open-weight models that can be run locally, and newly trending GitHub projects that ship something usable.

Typical items include a model release or upgrade, a price or quota change, a ban or throttling event, a coding agent release, a relay or routing tool update, a self-hostable model release, and hands-on comparisons that help choose between models or plans.

Do not use this profile for content whose main value is infrastructure and operations work, general software-engineering practice, consumer hardware, finance-first market coverage, academic research without a usable artifact, or promotional material without substantive information.
